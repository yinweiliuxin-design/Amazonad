# Amazonad：VELLEN 亚马逊广告数据总仓库

一个仓库管三个站点，每个站点一个分支。切换分支：仓库首页左上角的分支下拉框（默认显示 main）。

| 分支 | 站点 | 现在有什么 |
|---|---|---|
| `uk` | 英国 amazon.co.uk | 10-10 至 10-21 的广告报告、竞品资料、10-22 的批量上传文件和错误报告 |
| `de` | 德国 amazon.de | 还没有数据 |
| `jp` | 日本 amazon.co.jp | 还没有数据 |
| `main` | — | 只放这份说明 |

## 每个分支的目录都一样

```
01_广告报告/<下载日期>_数据<开始>至<结束>/   广告后台导出的报告，只留本站点的行
02_竞品与市场/<日期>/                        卖家精灵、Google 趋势、竞品 Listing 报告
03_批量上传/<日期>/                          上传过的批量文件和错误报告
04_方案/                                     方案文档的链接
05_脚本/                                     生成批量文件、分析搜索词的脚本
```

- 报告文件名用亚马逊报告的英文名：Campaign.csv、Advertised_product.csv、Search_term.csv 等，日期写在文件夹名上。
- 广告后台导出的报告会把英国和德国混在一起（同一个广告账户）。放进分支前按“广告活动名称”或“预算货币”分开：英国 = GBP / 活动名以“英国”开头，德国 = EUR。

## 每周一怎么更新

1. 广告后台下载上周的「搜索词」「广告活动」「推广的商品」三份报告。
2. 发给 Claude，说“放进 uk 分支”（或 de / jp），由 Claude 分站点、建文件夹、提交。
3. 自己传也可以：在 GitHub 上切到对应分支 → 进 `01_广告报告` → Add file → Upload files。

## 注意

- 这个仓库是私有的。报告里有广告账户 ID，不要改成公开。
